Salticide: Toward Foundation-Model-Based Adaptive Gaze–EMG Interaction for People with Limb Loss

Abstract

Salticide is a proposed capability-aware desktop interface for people with limb loss, combining gaze, inertial sensing, and surface EMG. An adaptive controller adjusts each modality’s contribution according to individual capabilities, signal confidence, and interaction context. Gaze supports rapid targeting, inertial input enables fine adjustment, and EMG provides deliberate activation and click confirmation. The longer-term architecture will investigate pretrained biosignal representations and interaction-driven personalization to refine calibration, input weighting, and activation thresholds across sessions. Planned evaluation will compare gaze-only, fixed-fusion, adaptive-fusion, and longitudinally personalized control, assessing accuracy, throughput, unintended clicks, latency, calibration burden, comfort, and cross-session performance. The central question is whether adaptation can improve sustained usability while preserving predictable control.

Project highlights

  • Capability-aware fusion. Adapt gaze, motion, and EMG contributions to each user’s comfortable range of action.
  • Deliberate activation. Use EMG confirmation and release-to-rearm logic for click generation.
  • Interaction-driven personalization. Investigate session-to-session refinement through repeated use and explicit user feedback.
  • Foundation-model research. Compare pretrained EMG representations with task-specific baselines to test measurable benefits.
